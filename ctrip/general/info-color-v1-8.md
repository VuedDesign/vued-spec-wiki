# Ctrip信息色彩规范1.8

> **状态**：本页 v1.8 已定稿为 Ctrip Wiki 现行信息色彩规范，独立于旧版 `[[ctrip/general/info-color]]` v1.7 插件基线。`figma_plugin_active: false` 表示 v1.8 尚未接入 Figma 自动审核；v1.7 的 0.90 实测基线不能当作本版验证结果。本页已随 `ec038d9` 上传 GitHub；上传不等于插件已接入。

### 核心校验逻辑与全局规则 \(Global Rules\)



**校验范围说明**：此处"全局"指**整个页面**或**一个独立的内容模块**（如一屏完整的列表页、详情页、订单卡片组、内容频道楼层等），而非单一 Banner、单个 Tag 或单条字段。插件在扫描时以**顶级 Frame / Page / 被标注为 ****`Module`**** 的独立内容容器**作为最小校验单元，按以下面积占比规则依次执行：



|全局属性分类|色彩 Token 类型|推荐面积占比限制|插件校验逻辑 \(Plugin Rules Engine\)|报错/警告提示文案|
|---|---|---|---|---|
|**中性色**|`Token/Black-*`, `Token/White`|**\> 60%**|以顶级 Frame 或独立内容模块为校验单元，累加其内所有中性色图层的可见面积，除以模块总面积；若比值 \< 60% 抛出警告。|**页面中性色过少**：当前页面/模块中性色占比不足 60%，信息主次不清，视觉过于杂乱。注：品牌、营销相关等营造氛围特殊页面不受限制|
|**主色**|`Token/Blue-1`|**\< 30%**|以顶级 Frame 或独立内容模块为校验单元，累加 Blue\-1 色值的可见面积，除以模块总面积；若比值 \> 30% 抛出警告。|**主色滥用警告**：当前页面/模块主色占比已超过 30%，主色应仅用于关键交互点与核心聚焦区，请降级次要元素。注：品牌、营销相关等营造氛围特殊页面不受限制|
|**辅助/功能色**|`Token/Orange-1`, `Token/Red-1`, `Token/Green-1`, `Token/BlueGray-1`, `Token/Brown-1`|**\< 10%**|以顶级 Frame 或独立内容模块为校验单元，累加所有辅助/功能色的可见面积，除以模块总面积；若比值 \> 10% 抛出警告。|**视觉焦点分散**：当前页面/模块辅助与功能色总占比超过 10%，过多的强调色会导致用户失去视觉焦点。注：品牌、营销相关等营造氛围特殊页面不受限制|



> 说明：单个 Banner、Tag、字段等"局部构件"不参与全局占比校验，仅在「图层级 Token 校验字典」中按各自语义规则单独判定。
>

### 图层级 Token 校验字典



以下为具体的颜色知识库，已包含 Figma Token ID、Hex、匹配关键词逻辑、判定规则及反馈文案。



### 1\. UI Blue（品牌蓝）



> 定义：页面引导用户操作的核心视觉焦点，同时承担点评分的专属展示。
>
>



- **Token ID**：`Token/Blue-1`

- **Hex 映射**：`#006FF6`

- **语义标签**：`Primary Action` / `Link` / `Highlight` / `Rating Score`



|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景\(DO\)**|1\. 页面中的可点击文字（如："查看详情 \>"、"重新发送"）\<br\>2\. 信息中的核心高亮词（如：订单号、关键状态名）\<br\>3\. 主操作按钮内的文字\<br\>4\. 点评分 0\.1–5\.0 数字文本，可带分母如 4\.9/5，可带单位如 4\.9分，评分后可衔接形容词（超棒、很好、满意、不错等），以及点评分背景 Tag|
|**禁用场景\(DON'T\)**|1\. 大段正文/段落文字（\>20 字）直接使用\<br\>2\. 用于表示"报错/危险/成功/优惠"语义的文本\<br\>3\. 浅蓝色背景上使用（对比度需符合 WCAG AA 4\.5:1）|
|**插件触发条件**|规则 A：文本图层色值为 `#006FF6`，字符数 \> 20，且图层/父级名称不包含 `Link`、`Button`、`Rate`、`Score`、`Highlight` 等交互或高亮关键字。\<br\>规则 B：图层/父级名称包含 `Error`、`Warning`、`Fail`、`Danger` 等异常语义关键字，却使用了 `#006FF6`。|
|**插件报错文案**|情况 A：**文本字数过长**：不建议大段使用 Blue\-1，建议更换为 Token/Black\-1 \(\#111111\)。\<br\>情况 B：**异常提醒色误用**：异常提醒场景请勿使用品牌蓝，请更换为 Token/Red\-1 \(\#F5190A\)。|

### 2\. UI Orange（激励橙）



> 定义：优惠、折扣、价格及需要用户注意的**重点提醒（Attention）**。提示等级低于 `Token/Red-1 (#F5190A)` 的高等级警示；不是所有带有 `Warning` 语义的内容都应改为红色。
>
>



- **Token ID**：`Token/Orange-1`

- **Hex 映射**：`#FF5500`

- **语义标签**：`Promotion` / `Incentive` / `Price` / `Attention`（重点提醒，低于 `Token/Red-1 (#F5190A)` 的警示）



|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景\(DO\)**|1\. 优惠、折扣、立减、积分激励等营销文字（如："立减¥5"、"赠 100 积分"）\<br\>2\. 突出显示价格中的优惠部分\<br\>3\. 需要重点提醒但尚未达到 Red-1 警示等级的信息\<br\>4\. 主价格使用|
|**禁用场景\(DON'T\)**|1\. 系统级常规提示或辅助说明文案\<br\>2\. 高等级警示、报错、失败或危险信息（应使用 `Token/Red-1 (#F5190A)`）\<br\>3\. 无优惠/营销属性的常规文本高亮|
|**插件触发条件**|**规则 A（高等级警示误用）**：target 已可靠确认属于高等级警示／报错／失败／危险，却使用 `Token/Orange-1 (#FF5500)` → 提示改用 `Token/Red-1 (#F5190A)`。仅图层名含 `Warning` 或文案有一般提示词，不足以判为 Red；上下文不明时人工复核。<br>**规则 B（禁用态用色人工复核）**：target 已可靠确认是处于 `Disabled` / `Inactive` 状态的文字且使用 `Token/Orange-1 (#FF5500)` 时，仅提示设计师人工核对；`Token/Black-3 (#888888)` 是当前通用规范对禁用文字的推荐用色，**不是此处的自动替换要求或自动报错**。禁用状态与提示等级分开判断；文本出现“失败／错误／无法／禁止”等词时，须先确认是否真的为高等级警示，不单凭关键词升级为 Red。|
|**插件报错文案**|情况 A：**提示等级用色不符**：`Token/Orange-1 (#FF5500)` 可用于营销、价格与重点提醒；当前经确认属于更高等级的警示／报错／危险，请使用 `Token/Red-1 (#F5190A)`。<br>情况 B：**禁用态用色请人工复核**：经确认的禁用文字使用了 `Token/Orange-1 (#FF5500)`，请设计师核对是否需要按禁用态推荐用色 `Token/Black-3 (#888888)` 调整；这不是 Red 警示场景，不自动判错。|

### 3\. Red（警示红）



> 定义：高于 `Token/Orange-1 (#FF5500)` 重点提醒等级的警示（Warning／Alert）、报错与破坏性操作用色；必填星号、POI 热度分等其他已列用途仍按下表处理。
>
>



- **Token ID**：`Token/Red-1`

- **Hex 映射**：`#F5190A`

- **语义标签**：`Error` / `Danger` / `Warning` / `Alert`（高等级警示）/ `Popularity Score`



|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景\(DO\)**|1\. 强警示、报错提示、失败状态文字（如："支付失败"、"密码错误"）\<br\>2\. 高风险破坏性操作文字（如："删除"、"注销"）\<br\>3\. 表单必填项的星号标志 \*\<br\>4\. 热度分，0\.1 到 10 的热度分，用于 POI 景点热度分数\<br\>5\. 热卖（Hot）与即将售罄场景可使用 `Token/Red-1 (#F5190A)`（用户已确认）；须可靠识别相应业务单元，不能仅凭名称含 `Hot` 就将普通文字认作热卖|
|**禁用场景\(DON'T\)**|1\. 正向成功提示（如"保存成功"）\<br\>2\. 仅仅为了"好看/吸睛"用于非报错的普通高亮文字\<br\>3\. 尚未达到高等级警示的重点提醒，若无本节其他明确用途，应使用 `Token/Orange-1 (#FF5500)`|
|**插件触发条件**|**规则 A（非专属场景使用红色）**：target 使用 `Token/Red-1 (#F5190A)`，且经可靠证据确认既非强警示／报错／失败、也非破坏性操作、表单必填星号、POI 景点热度分、已确认的热卖（Hot）或即将售罄场景 → 报错。仅靠 `Warning` 图层名或单个提示词不能区分 Orange 重点提醒与 Red 警示；无法判清等级时先人工复核，不把必填星号或“删除”操作误判为普通提示。|
|**插件报错文案**|**高警示色滥用**：`Token/Red-1 (#F5190A)` 用于强警示／报错、破坏性操作、表单必填星号、POI 景点热度分及用户已确认的热卖（Hot）／即将售罄场景；当前若只是非警示级的重点提醒，且不属于其他 Red 明示用途，请使用 `Token/Orange-1 (#FF5500)`；普通辅助提示按其实际语义使用其他规范色，勿仅为吸引注意使用红色。|

### 4\. Green（安心绿）



> 定义：非价格类的正向反馈与安全保障信息。
>
>



- **Token ID**：`Token/Green-1`

- **Hex 映射**：`#06875A`

- **语义标签**：`Success` / `Trust` / `Safety`



|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景\(DO\)**|1\. 非价格因素的安心服务、正向状态（如："已保障"、"极速退款"、"检验合格"）\<br\>2\. 操作成功/完成的反馈提示|
|**禁用场景\(DON'T\)**|1\. 价格标签（如"¥99"），除非是特定的绿色涨跌大盘语义\<br\>2\. 常规可点击链接色|
|**插件触发条件**|规则 A：图层/父级名称包含 `Price` 且不包含 `PriceTrend`、`Fluctuation`、`Stock` 等涨跌大盘关键字，却使用了 `#06875A`。\<br\>规则 B：图层/父级名称包含 `Link`、`Href` 等链接语义关键字，却使用了 `#06875A`。|
|**插件报错文案**|**安心色误用**：非价格涨跌大盘场景，价格展示请勿使用 Green\-1，建议使用 Token/Orange\-1 \(\#FF5500\) 或 Token/Black\-1 \(\#111111\)；链接高亮请改用 Token/Blue\-1 \(\#006FF6\)。|

### 5\. BlueGray（深蓝灰/次级高亮）



> 定义：复杂信息层级中弱于主色的次要高亮。
>
>



- **Token ID**：`Token/BlueGray-1`

- **Hex 映射**：`#0F4999`

- **语义标签**：`Secondary Highlight` / `Dark Context Link`



|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景\(DO\)**|1\. 复杂信息层级中，弱于主色 Blue\-1 的次要信息高亮\<br\>2\. 浅蓝/灰色背景块内部的文本高亮|
|**禁用场景\(DON'T\)**|1\. 作为页面一级标题或主要正文使用\<br\>2\. 与 Blue\-1 在同一极小区域内混用导致层级混乱|
|**插件触发条件**|规则 A：文本字号 ≥ 18px 且图层/父级名称包含 `Title`、`Heading`、`H1` 等标题语义关键字，却使用了 `#0F4999`。\<br\>规则 B：色值为 `#0F4999` 与色值为 `#006FF6` 的图层同处于同一 Frame 内且相互间距 ≤ 8px（视觉上易混淆）。|
|**插件报错文案**|情况 A：**层级色误用**：大标题请使用 Token/Black\-1 \(\#111111\)，BlueGray\-1 仅适用于次级信息高亮。\<br\>情况 B：**层级色混用**：BlueGray\-1 与 Blue\-1 距离过近，易造成层级混乱，请拉开视觉间距或统一色值。|

### 6\. Brown（携程榜单棕）



> 定义：携程榜单专用色值。
>
>



- **Token ID**：`Token/Brown-1`

- **Hex 映射**：`#673114`

- **语义标签**：`携程榜单 Rank` / `携程榜单 Tag`  \(榜单专属独占\)



|**维度**|**条件定义与判定逻辑**|
|---|---|
|**推荐场景 \(DO\)：**|仅限用于 携程榜单 榜单单元内的所有元素：<br>1. 携程榜单 普通榜单，如上海全球旅客精选景点第9名，入选上海人气景点<br>2. 携程榜单 年度榜单，2026 China 100\-人气景点<br>3. 与 携程榜单 Logo 同属一个榜单单元的所有跟随描述文字（含排名、入选说明、榜单名、品类后缀），例如"第 9 名""入选上海人气景点""2026 China 100""人气景点"|
|**禁用场景 \(DON’T\)：**|1\. 携程榜单专属色不得挪用于非榜单类的普通文本、图标；2\. 禁止将 `#673114` 用于任何非携程榜单相关的业务字段；3\. Logo 使用了 `#673114`，但同一榜单单元内的描述文字未使用 `#673114`（视为漏用）。|
|**双向校验规则**|**榜单单元 \(携程榜单 Unit\) 识别与扩散**：以下任一条件构成榜单单元入口 —— \(a\) 图层/组件名称包含 `携程榜单`、`XiechengList`、`Best List Logo`，或为 携程榜单 官方 Icon 组件实例；\(b\) 文本节点命中榜单关键词/正则：排名类 \(`第\d+名`、`Top\s*\d+`、`No\.\s*\d+`、`Rank\s*\d+`、`Ranked\s*\d+(st|nd|rd|th)?`\)、入选类 \(`入选`、`上榜`、`荣登`、`Featured in`、`Listed on`、`Selected in`\)、榜单名类 \(`携程榜单`、`.*榜单`、`.*榜$`、`China 100`、`\d{4}\s*(China|Global|Asia)\s*\d+`、`年度榜单`、`精选(景点|酒店|美食)`\)、品类后缀 \(`人气(景点|酒店|榜)`、`全球旅客精选`、`旅客之选`\)。<br>**规则 A \(非法使用\)**：检测到色值为 `#673114`，但所在单元内不含 携程榜单 Logo，且文本内容不命中上述榜单关键词 \-\> 报错。<br>**规则 B \(漏用专有色\)**：单元内检测到 携程榜单 Logo **或** 文本命中榜单关键词，但单元内任一文本/图标色值 ≠ `#673114` \-\> 报错（覆盖两种情况：整个单元漏色；Logo 已使用 `#673114` 但同单元跟随描述文字未同步使用 `#673114`）。|
|**插件报错文案**|携程榜单 专有色违规提示：<br>情况 A：`#673114` 是 携程榜单 专有色，严禁将其用于非榜单类 UI 元素或普通文本。<br>情况 B：检测到 携程榜单 榜单单元，请确保 Logo、排名文本及跟随的榜单描述文案必须且只能使用 Brown\-1 \(`#673114`\)；若 Logo 已使用榜单色但相邻描述文字（"XX"）未同步，请一并修正为 `#673114`，二者同属一个榜单单元需保持一致。|

### 7\. Black\-1（主要中性色）



> 定义：构建页面客观描述的一级信息层级。
>
>



- **Token ID**：`Token/Black-1`

- **Hex 映射**：`#111111`

- **语义标签**：`Primary Text` / `Title`



|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景\(DO\)**|1\. 页面大标题、卡片标题、主正文\<br\>2\. 需要强调的客观数据/关键数值\<br\>3\. 客观描述价格色使用（无需强调价格场景，保持流程内一致）|
|**禁用场景\(DON'T\)**|1\. 提示性/占位符文本 \(Placeholder\)\<br\>2\. 禁用状态 \(Disabled\) 的文字|
|**插件触发条件**|**规则 A（录入项暗提示）**：target 经可靠结构确认是查询框、表单等录入项的暗提示，且文字色为 `#111111` → 提示改用 `Token/Black-5 (#C5C5C5)`；仅名称含 `Hint` / `Placeholder` 但无法确认录入项归属时先人工核对。<br>**规则 B（禁用状态）**：target 已确认处于 `Disabled` / `Inactive` 状态，文字色为 `#111111` → 提示改用 `Token/Black-3 (#888888)`。|
|**插件报错文案**|情况 A：**录入项暗提示过深**：经确认的查询框／表单暗提示默认使用 `Token/Black-5 (#C5C5C5)`；若灰色背景上可读性差，可由设计师加深为 `Token/Black-4 (#AAAAAA)`，不要使用 `Token/Black-1 (#111111)`。<br>情况 B：**禁用文字层级误用**：经确认的禁用状态文字请使用 `Token/Black-3 (#888888)`，不要使用 `Token/Black-1 (#111111)`。|

### 8\. Black\-2（次级中性色）



> 定义：主文本之外的二级信息补充。
>
>



- **Token ID**：`Token/Black-2`

- **Hex 映射**：`#555555`

- **语义标签**：`Secondary Text` / `Subtitle`



|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景\(DO\)**|1\. 次要描述文本、副标题、表单 Label\<br\>2\. 对主正文进行补充说明的次级段落|
|**禁用场景\(DON'T\)**|1\. 页面最核心的标题（层级不够突出）\<br\>2\. 深色背景下使用（对比度不足）|
|**插件触发条件**|规则 A：图层/父级名称包含 `Title`、`Heading`、`H1`，且字号 ≥ 18px、Font\-Weight ≥ Bold \(700\)，却使用了 `#555555`。\<br\>规则 B：文本图层色值为 `#555555`，与其所处背景通过 Color Contrast Ratio 算法计算对比度 \< 4\.5:1。|

### 10\. Black\-5（辅助中性色）



> 定义：查询框及表单等录入项的暗提示。
>
>



- **Token ID**：`Token/Black-5`

- **Hex 映射**：`#C5C5C5`

- **条件例外 Token ID**：`Token/Black-4`

- **条件例外 Hex 映射**：`#AAAAAA`

- **灰底可读性例外**：默认使用 `Token/Black-5 (#C5C5C5)`；若该色在灰色背景上可读性差，设计师可加深为 `Token/Black-4 (#AAAAAA)`。灰底及可读性的机器阈值尚未定义；由设计师按实际画面判断。`Token/Black-4 (#AAAAAA)` 不是 Black-5 的另一 Hex 映射。

- **语义标签**：`Input Hint` / `Placeholder`



|维度|条件定义与判定逻辑 (Plugin Rules Engine)|
|---|---|
|**推荐场景 (DO)**|查询框、表单等录入项尚未录入内容时的暗提示／占位文字默认用 `Token/Black-5 (#C5C5C5)`；若在灰色背景上可读性差，可加深为 `Token/Black-4 (#AAAAAA)`，由设计师判断。|
|**禁用场景 (DON'T)**|不要把输入后的真实内容或表单字段标签误当作暗提示；本次新增仅确认录入项暗提示用途，不推导其他文本场景的禁用规则。|
|**插件触发条件**|**target**：已可靠确认为 Ctrip 通用查询框、表单等录入项内的暗提示文字；不得仅凭图层名称包含 `Placeholder` / `Hint` 就认领，也不审核已由 brand / feature 规范认领的图层。<br>**规则 A（暗提示色值越界）**：target 的最终文字色值若既不是默认的 `Token/Black-5 (#C5C5C5)`，也不是条件例外 `Token/Black-4 (#AAAAAA)` → 待插件负责人确认身份后提示。<br>**规则 B（条件例外人工复核）**：若 target 使用 `Token/Black-4 (#AAAAAA)`，应由设计师核对背景确为灰色且 `Token/Black-5 (#C5C5C5)` 在该背景上可读性差；不满足时改回默认 Black-5。若 target 在灰底使用默认 Black-5 但不易辨识，可提示设计师考虑 Black-4。因灰底和可读性缺少机器阈值，**规则 B 只作人工复核，不自动判错**；非录入项暗提示的图层也不得仅凭上述色值被本规则认领。|
|**插件报错文案**|情况 A：**[ctrip/info-color/black-5] 录入项暗提示色不符**（待启用）：已确认的查询框／表单暗提示默认使用 `Token/Black-5 (#C5C5C5)`；若在灰色背景上可读性差，设计师可改为 `Token/Black-4 (#AAAAAA)`。<br>情况 B：**[ctrip/info-color/black-5] 灰底加深条件请人工复核**：该暗提示使用了 `Token/Black-4 (#AAAAAA)`；请确认背景为灰色且默认的 `Token/Black-5 (#C5C5C5)` 不易辨识。不满足时恢复默认色；此项不自动判违规。|
