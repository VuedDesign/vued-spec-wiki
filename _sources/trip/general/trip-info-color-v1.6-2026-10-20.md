# Trip 信息色彩规范1\.6

### 核心校验逻辑与全局规则 \(Global Rules\)



**校验范围说明**：此处"全局"指**整个页面**或**一个独立的内容模块**（如一屏完整的列表页、详情页、列表页商品卡片组、订单卡片组、内容频道楼层等），而非单一 Banner、单个 Tag 或单条字段。插件在扫描时以**顶级 Frame / Page / 被标注为 ****`Module`**** 的独立内容容器**作为最小校验单元，按以下面积占比规则依次执行：



|全局属性分类|色彩 Token 类型|推荐面积占比限制|插件校验逻辑 \(Plugin Global Rules\)|报错/警告提示文案|
|---|---|---|---|---|
|**中性色**|`Neutral/*`|**\> 60%**|以顶级 Frame 或独立内容模块为校验单元，累加其内所有中性色图层的可见面积，除以模块总面积；若比值 \< 60% 抛出警告。|**页面中性色过少**：当前页面/模块中性色占比不足 60%，信息主次不清，视觉过于杂乱。注：品牌、营销相关等营造氛围特殊页面不受限制|
|**主色**|`Brand`|**\< 30%**|以顶级 Frame 或独立内容模块为校验单元，累加 Brand 色值的可见面积，除以模块总面积；若比值 \> 30% 抛出警告。|**主色滥用警告**：当前页面/模块主色占比已超过 30%，主色应仅用于关键交互点与核心聚焦区，请降级次要元素。注：品牌、营销相关等营造氛围特殊页面不受限制|
|**辅助/功能色/专有色**|`Functional/*`, `Discount`|**\< 10%**|以顶级 Frame 或独立内容模块为校验单元，累加所有功能色及强调色的可见面积，除以模块总面积；若比值 \> 10% 抛出警告。|**视觉焦点分散**：当前页面/模块辅助与功能色总占比超过 10%，过多的强调色会导致用户失去视觉焦点。注：品牌、营销相关等营造氛围特殊页面不受限制|



> 说明：单个 Banner、Tag、字段等"局部构件"不参与全局占比校验，仅在「图层级 Token 校验字典」中按各自语义规则单独判定。

### 图层级 Token 校验字典 \(Layer Logic Rules\)



以下为具体的颜色知识库，已包含 **Figma Token ID、Hex、RGB/OKLCH、匹配关键词逻辑、判定规则及反馈文案**。



### 1\. 品牌色 Brand Color \(Static\)



> **定义**：Trip 静态品牌色，仅用于极少数全局强品牌感知的场景。
> 
> 



- **Token ID**: `color-brand-static-blue` \| `color-brand-static-yellow`

- **Hex 映射**: `#2346FF` \(TripBlue\) \| `#FFB400` \(TripYellow\)

- **语义标签: **`Brand Identifier` / `Logo` / `Brand Banner` / `Copyright`

|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景 \(DO\)**|图层位于品牌专属组件内（如：`Header/Logo`、`Card/BrandBanner`、`Footer/CopyRight`）。|
|**禁用场景 \(DON'T\)**|常规 UI 控件（按钮、常规标签、图标、正文、背景）。|
|**插件触发条件**|当图层使用了 `#2346FF` 或 `#FFB400`，且其组件路径/图层名称**不包含** `Logo`, `Brand`, `Header` 关键字。|
|**插件报错文案**|**品牌色误用**：`TripBlue / TripYellow` 为品牌静态色，不可直接用于常规 UI 界面控件。交互主色请改用交互主色 Token `Brand (#2C61FE)`。|

> 
> 



- **Token ID**: `color-brand-primary`

|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|

### 3\. 功能色 \- 积极 Positive \(Cyan\)



> **定义**：用于传递对用户有利的正向信息、减价及低价区间。
> 
> 



- **Token ID**: `color-functional-positive`

- **Hex 映射**: `#047C88`

- **语义标签: **`Positive Status` / `Price Deduction` / `Low Price Range`

|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景 \(DO\)**|1\. 利好信息标签（如：“免费取消”、“含早餐”）\<br\>2\. 价格明细中的减价/优惠数值（如：“\-$20”）\<br\>3\. 价格区间中的“低价区间”标识|

> 
> 



- **Token ID**: `color-functional-warning`

- **Hex 映射**: `#C74401`

- **语义标签: **`Caution Notice` / `Price Increase` / `Medium Price Range` / `Risk Alert`

|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景 \(DO\)**|1\. 需关注的出行提醒（如：“需办理过境签”）\<br\>2\. 供应商/航司导致的价格自然上涨\<br\>3\. 价格划分中的“中价区间”|

### 5\. 功能色 \- 严重警告/热门 Alert \& Popular \(Red\)



> **定义**：极高风险阻断信息、高价区间、报错及热卖标。
> 
> 



- **Token ID**: `color-functional-danger`

- **Hex 映射**: `#D02C2A`

- **语义标签**: `Critical Alert` / `System Error` / `High Price Range` / `Popular Badge` / `Popularity Score`

|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景 \(DO\)**|1\. 影响出行成功与否的严重阻断信息\<br\>2\. 价格划分中的“高价区间”\<br\>3\. 系统 Error 报错提示\<br\>4\. 热门/热卖商品 Badge（如：“Selling Fast”）\<br\>5\.商品即将售罄（如Only 1 left at this price）\<br\>6\.热度分，0\.1到10的热度分，用于Poi景点热度分数|
|**禁用场景 \(DON'T\)**|普通提示、减价优惠、无风险的客观描述。|
|**插件触发条件**|图层非报错/非热卖组件，非即将售罄（如Only 1 left at this price），且无阻断语义（如普通提示框），非景点热度分，使用了 `#D02C2A`。|
|**插件报错文案**|**高警示色滥用**：红色 `Alert/Popular` 视觉冲击力强，仅限严重报错、高价区及热卖、Poi景点热度分场景。普通提示请改用 `Warning` 或 `Brand`。|

### 7\. 专有色 \- 点评分 Rate \(Indigo Blue\) 【严格独占规则】



> **定义**：点评分（Rating Score）的**唯一**专有颜色，具备双向排他性。
> 
> 



- **Token ID**: `color-specific-rate`

- **Hex 映射**: `#173CD2`

- **语义标签: **`Rating Score` / `Rating Tag` \(专属独占\)

|维度|条件定义与判定逻辑 \(Plugin Rules Engine\)|
|---|---|
|**推荐场景 \(DO\)**|**有且仅有**：0\.1到5\.0点评分数文本。形式上可以带分母如4\.9/5，可以单分子加单位，如4\.9分。评分后可衔接分数形容词，超棒、很好、满意、不错等等。点评分背景 Tag。|
|**禁用场景 \(DON'T\)**|1\. 点评分**使用以外**的任何色值\<br\> 2\. Rate 颜色用于点评分**以外**的任何 UI 元素 3\.含recommended、reviews字段、则评价字段均不属于点评分。|
|**双向校验规则**|**规则 A \(非法使用\)**：色值为 `#173CD2`，但图层/父级名称不含 `Rate`, `Score`, `则评价`  \-\> **报错**。\<br\>**规则 B \(漏用专有色\)**：图层/父级名称包含 `Rate`, `Score`，但色值 `!= #173CD2` \-\> **报错**。|
|**插件报错文案**|**点评分专有色违规**：\<br\>情况 A：`Rate (#173CD2)` 是点评分专有色，不可用于其他普通文本或控件。\<br\>情况 B：检测到点评分组件，点评分必须且只能使用 `color-specific-rate (#173CD2)`。|

### 8\. 专有色 \- Trip Best 【严格独占规则】

定义：Trip Best 榜单的唯一专有颜色，具备双向排他性。

- **Token ID**: `color-specific-trip-best`

- **Hex 映射**: `#673114`

- **语义标签**: `Trip Best Rank` / `Trip Best Tag` \(榜单专属独占\)

|**维度**|**条件定义与判定逻辑**|
|---|---|
|**推荐场景 \(DO\)：**|仅限用于 Trip Best 榜单单元内的所有元素：<br>1. Trip Best 普通榜单，如上海全球旅客精选景点第9名，入选上海人气景点<br>2. Trip Best 年度榜单，2026 China 100\-人气景点<br>3. 与 Trip Best Logo 同属一个榜单单元的所有跟随描述文字（含排名、入选说明、榜单名、品类后缀），例如"第 9 名""入选上海人气景点""2026 China 100""人气景点"|
|**禁用场景 \(DON’T\)：**|1\. Trip Best 专属色不得挪用于非榜单类的普通文本、图标；2\. 禁止将 `#673114` 用于任何非 Trip Best 相关的业务字段；3\. Logo 使用了 `#673114`，但同一榜单单元内的描述文字未使用 `#673114`（视为漏用）。|
|**双向校验规则**|**榜单单元 \(Trip Best Unit\) 识别与扩散**：以下任一条件构成榜单单元入口 —— \(a\) 图层/组件名称包含 `Trip Best`、`TripBest`、`Best List Logo`，或为 Trip Best 官方 Icon 组件实例；\(b\) 文本节点命中榜单关键词/正则：排名类 \(`第\d+名`、`Top\s*\d+`、`No\.\s*\d+`、`Rank\s*\d+`、`Ranked\s*\d+(st|nd|rd|th)?`\)、入选类 \(`入选`、`上榜`、`荣登`、`Featured in`、`Listed on`、`Selected in`\)、榜单名类 \(`Trip Best`、`.*榜单`、`.*榜$`、`China 100`、`\d{4}\s*(China|Global|Asia)\s*\d+`、`年度榜单`、`精选(景点|酒店|美食)`\)、品类后缀 \(`人气(景点|酒店|榜)`、`全球旅客精选`、`旅客之选`\)。<br>**规则 A \(非法使用\)**：检测到色值为 `#673114`，但所在单元内不含 Trip Best Logo，且文本内容不命中上述榜单关键词 \-\> 报错。<br>**规则 B \(漏用专有色\)**：单元内检测到 Trip Best Logo **或** 文本命中榜单关键词，但单元内任一文本/图标色值 ≠ `#673114` \-\> 报错（覆盖两种情况：整个单元漏色；Logo 已使用 `#673114` 但同单元跟随描述文字未同步使用 `#673114`）。|
|**插件报错文案**|Trip Best 专有色违规提示：<br>情况 A：`#673114` 是 Trip Best 榜单专有色，严禁将其用于非榜单类 UI 元素或普通文本。<br>情况 B：检测到 Trip Best 榜单单元，请确保 Logo、排名文本及跟随的榜单描述文案必须且只能使用 color\-specific\-trip\-best \(`#673114`\)；若 Logo 已使用榜单色但相邻描述文字（"XX"）未同步，请一并修正为 `#673114`，二者同属一个榜单单元需保持一致。|

### 9\. 中性色阶 Neutral Colors \(Black \& Gray\)



> **定义**：构建页面客观描述的信息层级。

> 



- **Token ID**: `color-text-primary` \| `color-text-secondary` \| `color-text-tertiary`
